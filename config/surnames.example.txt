# δεδομένων που υπάρχει η ροή για να αφαιρέσει.
#
# ΓΙΑΤΙ ΧΡΕΙΑΖΕΤΑΙ
# Η μορφολογία πιάνει τις διακριτές καταλήξεις — -όπουλος, -ίδης, -άκης,

# πρέπει να ονομαστούν.

# Το κενό φάνηκε μόνο όταν το εκπαιδευμένο μοντέλο τα εξέφερε: ρωτημένο για
# μια συνάντηση, απάντησε με δύο πραγματικά επώνυμα από το πανεπιστήμιο.

# ΠΩΣ ΦΤΙΑΧΝΕΤΑΙ
#   python3 scripts/mine_surnames.py --min-count 3
# Το script προτείνει· δεν αποφασίζει. Η απόφαση για το ποιο είναι όνομα
# ανθρώπου μένει ανθρώπινη.
